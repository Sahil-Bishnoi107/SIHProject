Viability: Will it be used?

Technical

Own 2D shallow-water + SPH solvers in C# / .NET 8. Exports Delft3D FM and DualSPHysics cases.

  • SPH near-field 1–3 km, 2D model 20–100 km
  • Checked vs Ritter exact solution: L1 2.9%

Data

All inputs free: SRTM terrain tiles, Sentinel-1/2, OpenStreetMap, CWC / India-WRIS dam records.

  • Takes lake detections from Sentinel-1/2 scans (GEE)
  • Zero ground sensors needed

Financial

Open-source stack running on free cloud tiers. Runs on CPU, no GPU needed.

  • ₹0 data and software licence cost
  • No paid solver or GIS licence

Operational

Docker + job queue; offline mode with cached terrain for air-gapped (NTRO) use.

  • One-command Docker deploy
  • Outputs .shp, .kml, PDF, CAP
